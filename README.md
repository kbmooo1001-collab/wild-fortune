# Wild Fortune (가칭)

몬스터 변이와 획득 장비 수식어를 추가할 Fabric 모드 프로젝트입니다.
현재 버전은 0.9.3입니다. 아래 표의 확률·수치는 기본 설정이며 설정 파일에서 조정할 수 있습니다. 몬스터 변이와 이름표, 장비 효과 30종의 독립 추첨과 조합별 이름을 지원합니다.

## 몬스터 효과

일반 몬스터가 자연 생성되거나 구조물과 함께 새로 생성될 때 다음 네 변이 효과를 각각 독립적으로 35% 확률로 부여합니다.

| 효과 | 확률 | 레벨 | 지속 시간 |
| --- | --- | --- | --- |
| 신속 | 35% | I | 무기한 |
| 저항 | 35% | I | 무기한 |
| 힘 | 35% | I | 무기한 |
| 최대 체력 증가 | 35% | +25% | 영구 |

0~4개가 동시에 적용될 수 있습니다. 모드가 부여하는 효과가 없는 확률은 17.8506%,
2개 이상 받는 확률은 43.7019%입니다. 바닐라 자체 효과는 그대로 유지합니다.
신속·저항·힘은 기본 상태 효과입니다. 힘이 모든 원거리 공격을 강화하지는 않습니다.
체력 변이는 원래 최대 체력의 25%를 더합니다. 예를 들어 좀비는 20 → 25 HP이며 새로 생성될 때 늘어난 체력까지 채웁니다.
기존 투명화 변이는 개체를 불러올 때 체력 변이로 한 번 교체하고, 남은 체력 비율과 저장된 등급을 보존합니다.

대상은 Minecraft의 MONSTER 분류이며 기본 설정에서 위더·엔더 드래곤을 제외합니다. 제외 ID 목록은 설정할 수 있습니다.
NATURAL과 STRUCTURE 생성 사유를 허용합니다. 난폭한 피글린 등 구조물 몬스터도 같은 설정으로 추첨합니다.
생성기, 스폰 알, 명령 소환, 증원 등 다른 생성 사유는 제외합니다.
구조물 NBT 로드 이후 적용 대상 태그를 복원하며, 이미 생성되어 저장된 미처리 몬스터에는 소급 적용하지 않습니다.
기존 월드의 이미 존재하던 개체에는 소급 적용하지 않습니다.
효과와 판정 완료 태그를 저장하므로 재로드 시 재추첨하지 않습니다.
효과가 제거되더라도 다시 부여하지 않습니다.

### 머리 위 이름

처음 이름을 부여할 때 신속·저항·힘 및 체력 변이 개수를 기준으로 등급을 정합니다.
0개는 기본 이름을 유지합니다. 모드가 붙인 이름표는 플레이어 위치로부터
일반 몬스터는 15칸 이내, 투명화 상태는 6칸 이내에서만 표시됩니다.
정확히 15칸/6칸인 경계도 포함하며, 수직 차이를 포함한 3차원 거리입니다.
현재 투명화 여부에 따라 표시 거리가 즉시 바뀝니다. HUD 표시 설정은 그대로 따릅니다.
몬스터 변이 이름은 지형의 깊이 판정을 따라 벽에 가려진 부분이 보이지 않습니다. 벽을 통과하는 별도 표시 단계는 생략하며, 기존 색상·굵기·프리즘과 거리 판정은 유지합니다. 플레이어 이름과 명찰로 직접 붙인 이름에는 적용하지 않습니다.

| 효과 개수 | 한국어 이름 예시 | 영어 이름 예시 | 색상 |
| --- | --- | --- | --- |
| 1 | 변이한 좀비 | Mutated Zombie | 빨강 |
| 2 | 강화된 좀비 | Empowered Zombie | 주황·굵게 |
| 3 | 흉포한 좀비 | Ferocious Zombie | 선홍·굵게 |
| 4 | 재앙의 좀비 | Calamitous Zombie | 붉은 프리즘·굵게 |

게임 언어가 한국어이면 한국어로, 영어이면 영어로 표시됩니다. 장비와 같은 색·굵기·프리즘 체계를 사용하며 별·해골·밑줄은 넣지 않습니다. 기존 몬스터의 저장된 등급은 유지합니다. 기존 투명화 변이만 체력 변이로 교체합니다.
투명화한 몬스터도 6칸 이내에서는 몸은 투명한 채 이름표를 표시합니다.
0.2.0에서 이미 판정을 마친 몬스터는 재로드할 때 현재 남아 있는 네 효과 수로 이름을 받습니다.
명찰 등으로 미리 정한 이름은 덮어쓰지 않습니다. 최초 등급은 저장되며,
이후 외부 효과 추가·제거에 맞춰 이름을 매 틱 변경하지 않습니다.
자동 이름 부여만으로 몬스터의 자연 소멸이 막히지 않습니다.

### 몬스터 이름 확률

권한 없이 `/wildfortune chance monsters`로 현재 서버 설정의 이름별 최종 확률을 확인합니다. 확률이 높은 순으로 정렬하며, 일반(이름표 없음)도 표시합니다. 자연·구조물 생성 변이 대상 몬스터만 기준으로 계산합니다.

| 이름 | 기본 확률 |
| --- | --- |
| 변이한 | 38.4475% |
| 강화된 | 31.0538% |
| 일반 | 17.8506% |
| 흉포한 | 11.1475% |
| 재앙의 | 1.5006% |

### 게임에서 확인

명령어가 허용된 월드에서 새 몬스터가 자연 생성된 후 아래 명령어로 가장 가까운
판정 완료 몬스터의 효과를 조회합니다. 이 버전의 `tag=` 선택자 옵션은
콜론이 포함된 이 태그 이름을 직접 읽지 못하므로 NBT 조건을 사용합니다.

```mcfunction
/data get entity @e[nbt={Tags:["wildfortune:mutations_rolled_v1"]},sort=nearest,limit=1] active_effects
```

최대 체력 변이는 상태 효과 목록 대신 최대 체력 속성에 저장됩니다.
`duration: -1`은 무기한 지속입니다. 전체 개체 데이터를 보려면 끝의 `active_effects`를 빼세요.
`Expected end of options`는 선택자 문법 오류입니다. `tag=` 대신 위 NBT 조건을 사용하세요.
`No entity was found`는 현재 차원에서 로딩된 판정 완료 개체를 찾지 못했다는 뜻입니다.
자연 생성된 새 몬스터가 있는지 확인하세요. 스폰 알·명령 소환은 판정 대상이 아닙니다.

## 획득 장비 수식어

플레이어가 획득한 내구도가 있는 비중첩 장비에, 허용된 효과를 각각 독립적으로 30% 확률로 추첨합니다.
제작·상자 전리품·몬스터 드롭·주민 거래·낚시·보상·명령 지급·크리에이티브 획득·자동 제작기 등 경로에 관계없이 적용합니다.
미처리 장비가 인벤토리·장착 슬롯·커서에 들어오면 다음 서버 틱(통상 0.05초 이내)에 한 번 판정합니다. 이전에 가지고 있던 미처리 장비도 적용합니다.
긍정 15종·부정 15종이며 0개부터 여러 개까지 함께 붙습니다. 효과가 없는 결과도 재추첨하지 않습니다.
같은 능력치의 긍정·부정 효과가 모두 성공하면 둘 다 제거합니다. 제거된 효과는 이름·설명·능력치에 반영하지 않습니다. 기존 0.5.0 장비도 같은 규칙으로 읽습니다.
남은 효과가 없는 장비는 회색의 `평범한 철 검`처럼 표시합니다. 제작 전 미리보기나 미처리 장비에는 붙이지 않습니다.
기본 설정에서 각 효과의 추첨 확률은 30%이며, 반대 효과와 상쇄되지 않고 실제 남을 확률은 각각 21%입니다. 확률 변경 시 실제 남는 확률도 바뀝니다.
기존의 긍정 60%·부정 40% 단일 추첨 규칙은 사용하지 않습니다.

| 긍정 | 효과 | 부정 | 효과 | 대상 |
| --- | --- | --- | --- | --- |
| 날카로운 | 근접 공격력 +10% | 무딘 | 근접 공격력 -10% | 근접 무기 |
| 효율적인 | 채굴 속도 +10% | 둔한 | 채굴 속도 -10% | TOOL 컴포넌트가 있는 도구 |
| 견고한 | 해당 부위 방어 수치 +10% | 허술한 | 해당 부위 방어 수치 -10% | 방어 수치가 있는 방어구 |
| 튼튼한 | 최대 내구도 +20% | 연약한 | 최대 내구도 -20% | 대상 장비 전체 |
| 민첩한 | 공격 속도 +10% | 굼뜬 | 공격 속도 -10% | 근접 무기 |
| 긴 | 거리 +0.5칸 | 짧은 | 거리 -0.5칸 | 근접 무기·채굴 도구 |
| 가벼운 | 이동 속도 +5% | 무거운 | 이동 속도 -5% | 대상 장비 전체 |
| 안정적인 | 밀치기 저항 +10% | 휘청이는 | 밀치기 저항 -10% | 방어구·방패 |

| 박식한 | 경험치 +10% | 망각의 | 경험치 -10% | 도구·기타 장비 |
| 생명력의 | 최대체력 +1 | 쇠약한 | 최대체력 -1 | 방어구·겉날개·방패·기타 장비 |
| 비상하는 | 수평 비행속도 +5% | 추락하는 | 수평 비행속도 -5% | 겉날개 |
| 재정비의 | 방어불능시간 -10% | 지연된 | 방어불능시간 +10% | 방패 |
| 치명적인 | 원거리 피해 +10% | 미약한 | 원거리 피해 -10% | 활·석궁 |
| 기민한 | 당기기·장전시간 -10% | 망설이는 | 당기기·장전시간 +10% | 활·석궁 |
| 쾌속의 | 투사체속도 +5% | 느릿한 | 투사체속도 -5% | 활·석궁 |
장비별 허용 목록 — 모든 장비 최대 5개:

| 종류 | 효과 계열 5종 |
| --- | --- |
| 검·창·삼지창·철퇴 | 공격력, 공격속도, 사거리, 이동속도, 내구도 |
| 곡괭이·도끼·삽·괭이·가위 등 | 채굴속도, 작업거리, 이동속도, 내구도, 채굴 경험치 |
| 일반 방어구 | 방어력, 이동속도, 밀치기저항, 내구도, 최대체력 |
| 겉날개 | 비행속도, 이동속도, 밀치기저항, 내구도, 최대체력 |
| 방패 | 방어불능 회복, 이동속도, 밀치기저항, 내구도, 최대체력 |
| 활·석궁 | 원거리 피해, 준비시간, 투사체속도, 이동속도, 내구도 |
| 낚싯대 등 기타 내구도 장비 | 최대체력, 경험치, 밀치기저항, 이동속도, 내구도 |

도구 경험치는 직접 채굴할 때 블록에서 발생하는 경험치에 적용합니다. 기타 장비는 주 손에 들고 받는 경험치에 적용합니다.
소량 경험치의 소수 부분은 접속 중 누적합니다. 방패의 회복 효과와 지속 능력치는 보조 손에서 작동합니다.
최대체력 +1은 하트 반 개이며 장비 교체로 체력을 회복시키지 않습니다.
비행속도는 겉날개 착용 중 수평 이동에 적용하며 낙하 속도는 유지합니다. 매 틱 가속이 누적되지 않습니다.
사격 효과는 실제 발사한 활·석궁의 저장 수치를 사용합니다. 화살·폭죽 피해를 지원하며 무기를 교체해도 발사된 투사체 수치는 유지됩니다.
투사체 속도 변경은 바닐라 화살 피해 공식에도 영향을 줄 수 있습니다. 준비·회복 시간은 틱 단위로 반올림합니다.
거리 효과는 무기에서 엔티티 상호작용 거리, 도구에서 블록 상호작용 거리를 바꿉니다.
화살 사거리에는 적용하지 않습니다. 이동 속도는 장비 슬롯별 기본 속도 배율을 합산합니다.
밀치기 효과는 받는 밀치기 강도를 각각 10% 줄이거나 늘려, 기본 저항이 없는 방어구에도 부정 효과가 작동합니다.

상쇄 후 효과가 1개면 기존 수식어(날카로운, 가벼운 등)를 유지합니다.
2개 이상이면 효과 종류와 관계없이 긍정·부정 효과의 개수만으로 아래 이름 하나를 붙입니다.
예를 들어 공격력+공격속도와 내구도+이동속도는 모두 긍정 2개이므로 `우수한 철 검`입니다.
기존 장비에도 즉시 같은 이름 규칙을 적용하며, 개별 효과 이름을 이어 붙이지 않습니다.

| 긍정 | 부정 | 이름 |
| --- | --- | --- |
| 2 | 0 | 우수한 |
| 1 | 1 | 양면의 |
| 0 | 2 | 불길한 |
| 3 | 0 | 명장의 |
| 2 | 1 | 거친 |
| 1 | 2 | 불안한 |
| 0 | 3 | 저주받은 |
| 4 | 0 | 영웅의 |
| 3 | 1 | 비범한 |
| 2 | 2 | 혼돈의 |
| 1 | 3 | 위태로운 |
| 0 | 4 | 파멸의 |
| 5 | 0 | 전설적인 |
| 4 | 1 | 불완전한 |
| 3 | 2 | 격동의 |
| 2 | 3 | 뒤틀린 |
| 1 | 4 | 비운의 |
| 0 | 5 | 재앙의 |

현재 장비별 허용 계열과 상쇄 규칙상 한 아이템에 남는 효과는 최대 5개입니다.
이름 강조: 긍정 1~2개 초록 / 3개 밝은 청록 굵게 / 4개 밝은 보라 굵게 / 5개 청백색 프리즘·흐르는 반짝임. 부정 1~2개 빨강 / 3개 주황 굵게 / 4개 선홍 굵게 / 5개 붉은 프리즘·흐르는 반짝임. 혼합은 금색, 무효과는 회색입니다.
최고 등급 이름은 글자마다 색과 밝기가 부드럽게 흐릅니다. 인벤토리·손에 든 이름·채팅 확률표의 해당 이름에 적용하며, 확률 숫자나 일반 글자는 반짝이지 않습니다. 전용 폰트는 바닐라 글꼴을 참조하므로 글자 형태·번역·폭을 유지합니다.
툴팁은 `공격력 +10%`, `사거리 +0.5칸`처럼 한 능력치당 한 줄로 간단히 표시합니다.

방어 수치 10%는 피해 감소율 10%와 다릅니다. 공격력 효과는 주 손 근접 공격 속성에 적용되며
활·석궁의 원거리 피해를 바꾸지 않습니다.
내구도는 정수로 반올림하며 최솟값은 1입니다. 채굴 효과는 주 손 장비의 최종 채굴 속도에 적용됩니다.
방어 효과는 원래 방어구 슬롯에서만 적용됩니다.

- 제작 미리보기에는 추첨하지 않습니다. 결과를 가져올 때 서버가 판정합니다.
- 일반 제작, 2x2 제작, Shift 제작, 숫자키 수령을 지원합니다. Shift 제작도 장비마다 한 번씩 추첨합니다.
- 인벤토리가 꽉 차서 Shift 제작에 실패하면 추첨하거나 재료를 소모하지 않습니다.
- 몬스터 이름, 장비 수식어와 효과 설명은 게임 언어 설정을 따릅니다. 한국어(ko_kr)는 한글, 영어는 영어로 표시하며, 이미 얻은 장비와 몬스터도 언어 전환에 맞춰 번역됩니다.
- 기존 장비나 `/give`, 크리에이티브 목록에서 얻은 장비에는 소급해서 추첨하지 않습니다.
- 자동 제작기 결과도 플레이어가 획득하면 판정합니다. 상자 안의 미획득 전리품·주민 판매 목록·제작 미리보기는 판정하지 않습니다.
- 수식어는 아이템 custom_data에 저장되어 상자 보관·드롭·재접속 후에도 유지됩니다.
- 모루 수리·이름 변경, 숫돌, 제작 수리, 대장장이 작업대 업그레이드는 재추첨하지 않습니다.
- 제작 수리와 숫돌 결합은 첫 번째 장비의 수식어를 계승합니다. 첫 번째가 일반 장비면 결과도 일반 장비입니다.
- 네더라이트 업그레이드는 수식어를 보존하면서 새 재질의 공격력·내구도를 사용합니다.
- 0.4.0의 단일 효과 장비도 계속 읽습니다. 장비 종류에 맞지 않는 과거 효과는 표시·적용하지 않습니다.

게임에서 확인하려면 철괴 2개를 대각선으로 배치해 가위를 제작하거나 작업대에서 검·곡괭이·방어구를 제작하세요.
미리보기 대신 실제로 받은 아이템 위에 마우스를 올려 수식어와 설명을 확인하면 됩니다.

6단계 설정 파일 분리는 0.6.0에서 완료했습니다.

개발용 게임은 작업 종료 후 최신 코드로 실행하고 타이틀 화면에 둡니다.
이미 실행 중이면 월드를 저장하고 정상 종료한 뒤 재시작합니다. 별도 요청 없이 게임 안에서 조작하거나 플레이 테스트하지 않습니다.

## 6단계: 설정 파일

실행하면 해당 게임 폴더의 `config/wildfortune.json`이 자동 생성됩니다.
이 프로젝트의 개발용 게임에서는 `run/config/wildfortune.json`입니다. 예제 원본은 `config/wildfortune.example.json`입니다.

- 몬스터: 전체 사용 여부, 제외할 엔티티 ID, 신속·저항·힘·투명화 각각의 사용 여부·확률·레벨.
- 장비: 전체 추첨 사용 여부, 30종 효과 각각의 사용 여부·확률·수치.
- 재시작하거나 관리자 권한(명령어 레벨 2 이상)으로 `/wildfortune reload`를 실행해 적용합니다.
- 설정은 새로 생성되는 몬스터와 처음 판정하는 획득 장비부터 적용합니다. 기존 대상은 재추첨하거나 수치를 바꾸지 않습니다.
- 장비 수치를 아이템에 함께 저장하므로 설정 변경·재접속·수리·업그레이드 후에도 같은 수치와 설명을 사용합니다.
- 0.5.x 이하 장비는 원래 기본 수치를 유지합니다. 서버에서 만든 장비는 클라이언트의 로컬 설정이 달라도 저장된 수치를 사용합니다.
- 문법 오류, 범위 초과, 항목 오타가 있으면 적용을 거부하고 기존 설정 및 원본 파일을 보존합니다. 첫 실행 실패 시 기본 설정을 사용합니다.
- 설정에서 꺼도 기존 효과를 지우지 않습니다. 장비 추첨을 끈 동안 획득한 장비는 회색 평범한 이름으로 확정합니다.
- 같은 계열의 긍정·부정이 함께 추첨되면 설정된 수치와 관계없이 둘 다 제거하는 기존 규칙을 유지합니다.

0.7.0은 기존 설정을 스키마 2로 확장하고 원본을 wildfortune.json.v1.bak으로 보존합니다. 기존 수정값은 유지하고 새 효과는 기본값을 채웁니다.
상세 항목·수치 단위·수정 예시는 `설정안내.md`에 있습니다. 실제 생존 및 두 클라이언트의 멀티플레이 검증은 후속 단계입니다.

## 수식어 확률 조회 — 권한 불필요

명령어는 `/wildfortune chance` 하나입니다. OP나 명령어 허용 설정 없이 사용하며, 종류별 하위 명령은 없습니다.
요청자에게만 최종 이름별 확률표를 표시합니다. T 키로 채팅을 펼치고 스크롤해 전체 표를 볼 수 있습니다.
개별 단일 이름은 모두 `수식어 1개` 행으로 합산합니다. 나머지 조합 이름과 평범한 결과는 각각 표시합니다.
정렬은 확률 내림차순입니다. 범위는 최댓값, 동률이면 최솟값을 기준으로 정렬합니다.
3~5개 긍정·부정 이름의 강조 스타일도 확률표에 반영합니다.
기본 설정은 모든 장비가 동일한 5계열·효과별 30%이므로 단일 23.7646%, 평범한 6.5636%, 양면의 17.2089%입니다.
상쇄와 동일 이름으로 합쳐지는 모든 결과를 계산하며, 기본 분포 합은 반올림 전 정확히 100%입니다.
효과별 확률을 다르게 설정하여 종류별 확률이 달라지면 한 표에 최솟값~최댓값 범위로 표시하고 안내합니다. 이 경우 범위 양끝을 합산하지 않습니다.
표시값은 소수점 넷째 자리까지 반올림하며 아주 희귀한 결과는 <0.0001%로 표시합니다.
새로 판정하는 획득 장비 기준이며 판정을 마친 보유 장비는 재추첨하지 않습니다. `/wildfortune reload`는 계속 관리자 전용입니다.

- 가능한 16가지 효과 조합 모두 확인, 레벨 I 및 무기한 지속 확인.
- 자연 생성 이외의 모든 생성 사유와 동물·주민·보스 제외 확인.
- 0개 및 4개 효과 개체를 바닐라 저장 형식으로 저장·복원하여 결과 보존 확인.
- 반복 로드 콜백에서 효과 재부여 방지 확인.

주요 결과는 `verification/stage-3-gametest.log`, 테스트 코드는 `src/gametest/`에 있습니다.
테스트 전용 모드는 배포 JAR에 포함되지 않습니다.
0.2.0 개발용 클라이언트의 로딩·초기화와 메인 메뉴 표시도 확인했습니다.
관련 로그는 `verification/stage-3-client-loading.log`입니다.

이전 0.1.0 검증: `build --no-daemon --offline` 성공. 컴파일 및 JAR 생성, 설정 캐시 저장을 확인했습니다.
2026-10-25 개발용 게임 실행 검증도 완료했습니다. `runClient --no-daemon`으로
Minecraft 26.3을 실행하여 `wildfortune 0.1.0` 로딩과 초기화 로그를 확인했습니다.
테스트 월드 `New World`를 생성하고 실제 플레이 화면과 일시 정지 메뉴까지 확인했습니다.
주요 확인 로그는 `verification/stage-2-loading.log`, 전체 실행 로그는 `run/logs/latest.log`에 있습니다.

Realms 및 온라인 인증 기능은 이번 검증 범위에 포함하지 않습니다.

## 개발 환경

2026-10-25 확인 기준으로 최신 정식 Minecraft 버전을 선택했습니다.
스냅샷은 사용하지 않으며 아래 의존성 버전을 고정합니다.

| 구성 | 버전 |
| --- | --- |
| Minecraft Java Edition | 26.3 |
| Fabric Loader | 0.20.1 |
| Fabric API | 0.165.0+26.3 |
| Fabric Loom | 1.19.3 |
| Gradle Wrapper | 9.8.2 |
| Eclipse Temurin JDK | 25.0.4.1+1, Windows x64 |

JDK는 `.tools/jdk/`에 있으며 시스템 Java 설정을 변경하지 않습니다.
Gradle 및 의존성 캐시는 `.tools/gradle-cache/`에 저장됩니다.
개발용 게임 데이터는 `run/`에 저장되며 실제 플레이 월드와 분리됩니다.

## 사용 방법

프로젝트 폴더에서 PowerShell을 열어 실행합니다.
첫 실행은 의존성을 다운로드하므로 인터넷 연결이 필요합니다.

```powershell
# 모드 빌드
powershell -NoProfile -ExecutionPolicy Bypass -File .\dev.ps1 build

# 개발용 게임 실행
powershell -NoProfile -ExecutionPolicy Bypass -File .\dev.ps1 runClient

# 개발용 소스 생성 (IDE에서 Minecraft 코드 참조)
powershell -NoProfile -ExecutionPolicy Bypass -File .\dev.ps1 genSources
```

빌드 결과는 `build/libs/wild-fortune-0.9.3.jar`입니다. 이전 버전과 동시에 설치하지 마세요.
`-sources.jar`는 소스 열람용입니다.
일반 런처에 설치할 때는 Minecraft 26.3용 Fabric 프로필과 같은 버전의 Fabric API가 필요합니다.
이 프로젝트는 기존 런처 프로필이나 `.minecraft` 폴더를 변경하지 않습니다.

IDE를 사용하는 경우 IntelliJ IDEA에서 이 폴더를 열고 Gradle JVM을
`.tools/jdk/jdk-25.0.4.1+1`로 선택하면 됩니다.

## 0.9.3 배포 설치

배포 ZIP의 mods 안에 있는 모드와 Fabric API를 사용할 게임 폴더의 mods에 넣고 실행합니다. 설정 파일을 옮길 필요가 없습니다. config/wildfortune.json이 없으면 장비 각 30%·몬스터 각 35%·최대 체력 +25% 설정을 자동으로 생성합니다. 기존 파일이 있으면 그대로 사용하며 덮어쓰지 않습니다. 이후 파일을 수정하고 /wildfortune reload(관리자 권한)를 실행해 조정할 수 있습니다.
